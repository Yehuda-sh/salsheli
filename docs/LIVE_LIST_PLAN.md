## פאזה 1 — שורש: הגדרה אחת ל"חוסר"

**הבעיה (מ-B2):** שתי הגדרות סותרות. `isLowStock` מתעלם מ-`quantity == 0`, אז ספירות "מה צריך לקנות" **לא סופרות פריטים שאזלו**.

**ההפרדה הנכונה:**
- `isMissing` = `quantity < minQuantity` (כולל 0) — **המקור היחיד** ל"שייך לרשימה / צריך לקנות".
- `isLowStock` = `quantity > 0 && < min` — **שכבת תצוגה בלבד** (צהוב).
- `quantity == 0` / `needsUrgentAttention` — שכבת תצוגה (אדום).
- כלומר: `missing = low ∪ out`.

**שינויים:**
- `inventory_item.dart`: getter `isMissing`.
- `inventory_provider.dart`: `getMissingItems()`.
- `main_navigation_screen.dart` + `app_layout.dart`: ספירות "צריך לקנות" → `getMissingItems()` (תיקון undercount).
- מסך המזווה: טאבי הסינון `lowStock`/`outOfStock` **נשארים נפרדים** (תצוגה — לא נוגעים).
- טסטים ל-`isMissing` + `getMissingItems`.

**קבלה:** קריטריון #1 — פריט מתחת למינימום (כולל 0) הוא "חוסר".
